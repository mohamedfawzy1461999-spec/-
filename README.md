# BIM Enterprise OS — النسخة الجاهزة للتشغيل

## ما الذي تغيّر في هذه النسخة؟
- تسجيل الدخول أصبح من السيرفر عبر `POST /api/login` باستخدام كلمات مرور مجزأة بـ scrypt وتوكنات JWT.
- تم إيقاف المصادقة القديمة بكود المزامنة افتراضياً. لا تفعّل `ALLOW_LEGACY=1`.
- مزامنة الحالة والبث اللحظي يستخدمان توكن الجلسة بدلاً من SAP وكود المزامنة أو مفتاح الأدمن.
- دخول البصمة/الدخول التجريبي المحلي لم يعد يمنح جلسة؛ لا بد من التحقق من حساب السيرفر.
- أول دخول بحساب مؤقت يطلب تغيير كلمة المرور، والسيرفر يمنع بقية API حتى يتم التغيير.
- إزالة كلمات المرور الافتراضية من واجهة HTML، ومنع إرسال كلمات مرور الموظفين/المديرين ضمن بيانات الحالة.
- إضافة اختبارات للمصادقة، وتحديث دليل التشغيل.

## التشغيل محلياً
يتطلب Node.js 18 أو أحدث.

```bash
npm install
export JWT_SECRET="$(node -e "console.log(require('crypto').randomBytes(48).toString('hex'))")"
export ADMIN_USER="bimadmin"
export ADMIN_PASS="ضع-كلمة-مرور-قوية-هنا"
export ADMIN_KEY="$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")"
node server.js
```

افتح `http://localhost:3000`. أول حساب أدمن يتم إنشاؤه من `ADMIN_USER` و`ADMIN_PASS` عند بدء السيرفر. محلياً يحفظ النظام في `data.json` و`auth.json`؛ لا تحذفهما إذا أردت الاحتفاظ بالبيانات والحسابات.

## النشر على Railway
1. ارفع مجلد المشروع إلى GitHub.
2. أنشئ خدمة PostgreSQL على Railway واربط `DATABASE_URL` بخدمة التطبيق.
3. أضف المتغيرات التالية في Variables:
   - `NODE_ENV=production`
   - `DATABASE_URL=${{Postgres.DATABASE_URL}}`
   - `JWT_SECRET` قيمة عشوائية طويلة وثابتة (48 بايت أو أكثر بصيغة hex).
   - `ADMIN_USER` اسم حساب الأدمن الأول.
   - `ADMIN_PASS` كلمة مرور قوية لحساب الأدمن الأول.
   - `ADMIN_KEY` مفتاح عشوائي مستقل لرفع ملفات هاشات الحسابات.
   - `ALLOW_ORIGIN` اتركه غير مضبوط عند استخدام الموقع من نفس نطاق Railway. لتطبيق Capacitor اضبطه على Origin التطبيق الفعلي مثل Origin الفعلي الظاهر في طلبات التطبيق (غالباً `https://localhost` على Android عند استخدام `androidScheme: https`، وقد يكون `capacitor://localhost` على منصات أخرى)، ولا تستخدم `*`.
4. انشر الخدمة. فحص Railway يستخدم `/healthz`.
5. افتح رابط الموقع وسجّل الدخول بحساب `ADMIN_USER` و`ADMIN_PASS`. اترك الصفحة مفتوحة حتى تظهر حالة الاتصال بالسيرفر وتكتمل أول مزامنة للبيانات المحلية.

**مهم:** لا تغيّر `JWT_SECRET` بعد النشر؛ تغييره يُبطل كل الجلسات الحالية. PostgreSQL مطلوب للاحتفاظ بالبيانات بين عمليات النشر على Railway. لا تعتمد على ملف JSON في نظام ملفات مؤقت.

## إنشاء حسابات الموظفين الأولية
بعد أول دخول للأدمن ورفع بيانات الموظفين إلى السيرفر:

```bash
npm run credentials:gen
```

ينتج ملفان محليان:
- `credentials.csv`: الأكواد المؤقتة لتسليمها للموظفين بشكل آمن.
- `credentials-import.json`: هاشات كلمات المرور فقط.

ارفع الهاشات إلى السيرفر:

```bash
node scripts/credentials.js push https://YOUR-APP.up.railway.app YOUR_ADMIN_KEY
```

وزّع الأكواد من `credentials.csv` على أصحابها عبر قناة آمنة، ثم اطلب منهم تسجيل الدخول وتغيير الكود المؤقت. لا ترفع أي ملف `credentials*` إلى GitHub ولا ترسله في مجموعة عامة.

## إعادة تعيين كلمة مرور موظف
من جهاز موثوق عليه Node.js:

```bash
node scripts/credentials.js reset https://YOUR-APP.up.railway.app ADMIN_USER ADMIN_PASS SAP
```

يعرض السكربت كلمة مرور مؤقتة مرة واحدة. سلّمها للموظف بأمان. أو استخدم `POST /api/admin/reset` بتوكن الأدمن.

## إضافة موظف عبر API
`POST /api/admin/users` يتطلب توكن أدمن، والحقول: `sap`, `name`, `username`, `password`, `branch`, `role`. يجب أن يكون الفرع موجوداً في بيانات النظام، وكلمة المرور 8 أحرف على الأقل. الحساب الجديد يُجبر على تغيير كلمة المرور عند أول دخول.

## الاختبارات
```bash
npm test
```

تتضمن الاختبارات: تجزئة كلمات المرور والتحقق منها، توقيع JWT وكشف العبث، محرك الجغرافيا والمخاطر، الهندسة الصناعية، والتحقق البصري.

## حدود يجب معرفتها قبل الاستخدام الحقيقي
- الاختبارات محلية وليست اختبار اختراق أو اختبار ضغط.
- لم يتم النشر على حساب Railway الخاص بك ولا يمكن تأكيد اتصال قاعدة البيانات الفعلية من هنا.
- تكامل GPS/Play Integrity/البصمة الأصلية في Android ليس بديلاً عن التحقق الأصلي من الجهاز؛ البصمة المحلية لا تُعتبر مصادقة سيرفر مستقلة.
- جدولة الورديات ما زالت خوارزمية جشعة وليست محللاً أمثل MILP.
- راجع `AUDIT_REPORT_AR.md` قبل إدخال بيانات حقيقية.
